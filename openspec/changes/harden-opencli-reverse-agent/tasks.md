## 2026-11-19 OC-WS-005/006 代际发布与停止竞态

`stopDuringConnectionSetupDoesNotPublishAnotherGeneration` 在连接线程读取端点时阻塞配置读取，随后调用 `stop()`，再解除阻塞。修复前本地中心收到已停止 worker 的注册消息，1 项失败，退出 1。修复后停止和连接发布共用同步边界，晚到连接无法发布。异常、关闭及退出均只退役对应 socket，当前代际检查用于注册、收单和异步结果投递。同一个已验证 TLS 中心显式重发仍可读取对应缓存。异常的默认日志保持固定文本。

## 2026-11-19 OC-WS-006 可重启停止

`restartableStopDropsQueuedCollectsAndCancelsPastDrainDeadline` 在回环中心提交持续心跳的真实 CLI 子进程，并填满等待队列。CLI 时限配置为 20 秒，确保 SDK 命令时限不会代替 Worker 的停止预算。旧实现返回后在途心跳仍递增，定向 1 项失败，退出 1。修复后 `stop()` 先停止准入、退役原连接、撤销未启动的排队任务，给已运行任务最多 5 秒收尾，再取消剩余任务。回归验证停止调用在 7 秒测试窗口内返回、心跳停止、排队任务没有启动、同一实例重连可接收任务。

已启动任务保留去重占位到实际执行收尾。等待任务撤销时释放占位。重连使用原有固定线程池及其容量。终态 `close()` 仍立即取消在途工作，丢弃队列并在共用预算内等待资源回收，关闭后拒绝重启。

JDK 17 定向 28 项通过。JDK 8 使用系统 Maven 执行 `-B -ntp -o clean verify`，2,122 项通过，0 失败、0 错误、0 跳过。显式连接状态机和独立平台资源验收仍由 2.1 和 3.3 跟踪。

## 2026-11-19 OC-WS-001 入站状态与消息上限

每条连接的状态从 `CONNECTING` 经 `REGISTERING` 到 `READY`，退役为 `RETIRED`。只有当前连接收到单个 JSON 对象的合法注册确认后才接单。WebSocket 解码使用默认 1 MiB 的有限上限，覆盖单帧和分片聚合，可在创建 Agent 前配置。超限在 JSON 解析和任务入队前关闭该连接，后续重连需要重新注册。

JDK 17 定向红灯复现三项失败，退出 1。拼接 JSON 错误推进注册，超长单帧和分片均未关闭连接。修复后验证合法确认仍可接单，两个超限场景均关闭连接、没有 CLI 标记且重新注册。发送单个超长帧时，接收方可能在对端写完前关闭连接，对端可观察到 1006 或 1009。分片超限场景验证 1009。补充拒绝零、负数及库定义的无限哨兵设置。JDK 17 定向 34 项通过。

JDK 8 使用系统 Maven 执行 `-B -ntp -o clean verify`，2,128 项通过，0 失败、0 错误、0 跳过。

## 2026-11-19 OC-WS-005 投递失败和旧协议兼容

在 TLS 回环环境向第一次结果发送注入异常，CLI 子进程实际写入执行标记。修复前中心等待第二次注册超时，定向 2 项中 1 项失败，退出 1。修复后失败连接退役。第二条连接完成注册和心跳时，中心仍未收到自动投递。中心显式重发相同请求后，收到原成功结果和 `cached: true`，`error` 为空，实际子进程标记始终为一条。日志捕获包含固定的投递失败消息，异常内测试密钥未出现在日志中。

旧协议夹具继续核对 register 的五个字段、pong 的单字段、成功与失败 result 的五个字段，以及实际进程收到的完整 argv。三个版本的直接字段断言通过。JDK 17 定向 35 项通过。JDK 8 使用系统 Maven 执行 `-B -ntp -o clean verify`，2,129 项通过，0 失败、0 错误、0 跳过。全量通过后单独复跑加严的旧协议字段断言，1 项通过。此处的诊断结论覆盖反向 Worker，跨传输隐私仍由 C09 跟踪。

## 2026-11-19 C05 压力、断线与资源收尾

`disconnectAndCloseReleaseBoundedWorkerResources` 通过回环 WS 中心启动两个持续心跳的真实 CLI 子进程，排队一项并拒绝一项超额请求，随后断开旧连接并重新注册。重连后，每项有效命令仍只执行一次，排队和超额请求均没有启动标记。观测到 2 个收单线程、1 个连接发起线程、2 个 stdout 与 2 个 stderr 读取线程。计数以场景前 JVM 线程集合为基线。

终态关闭后，上述线程和 SDK 的终止工作线程新增数回到零，两个真实子进程的心跳停止，执行标记仍为两条。Surefire 报告保留 `C05 resources: started=2 workerThreads=2 runnerThreads=1 readers=4 threadsAfterClose=0`。该计数覆盖 SDK 自有线程，回环中心和 Java-WebSocket 内部线程由各自生命周期管理。

JDK 8 使用系统 Maven 执行 `-B -ntp -o clean verify`，2,130 项通过，0 失败、0 错误、0 跳过。三条线在本地 macOS 得到相同观测。最新托管平台结果单独记录于 PR。
